# TimeTurn AI — 課題定義とコアバリュー

> **作成日**: 2025年2月15日
> **経緯**: しゅんすけ自身の原体験を深掘りし、TimeTurnが「誰の・どんな課題を解決するアプリなのか」を言語化するセッション

---

## 1. TimeTurnが向き合う人

**「やろう」とは思ってる。でも思ってるだけ。動くパワーがない人。**

- 目標はある（行きたい場所、なりたい姿）
- やり方もなんとなくわかってる
- 火はつく。でも数日で消える
- 消えるたびに自分を責めて、気合でまた火をつけようとして、また消える
- そのループで「俺は頑張れないやつだ」と思い込んでいく
- やれる人は勝手にやっていく。TimeTurnは「それができない人」のためのもの

**対象は「やる気がない人」ではない。「やりたいのに、一人じゃうまく自分を動かせない人」。**

---

## 2. 本当の課題（原体験から抽出）

### 表層の課題
- 勉強（やるべきこと）が続かない
- 結果が出ない

### 構造的な課題
1. **気合と意志力しか手段がない**
   - 「今日だけは世界一頑張る日にする」→ 数日で燃え尽きる
   - うまくいかないやり方を変えられず、脳筋で繰り返す
   - できなかった日の分を翌日に積み上げて、どんどん重くなる

2. **「できた」という手応えがゼロ**
   - 頑張ってるのに前に進んでる感覚がない
   - 自分を信じられない → ビビりながらやる → 手応えがない → さらに信じられない

3. **一人で抱えている**
   - できない自分を誰にも見せられない
   - 友達には大丈夫なふりをしている
   - 弱さを打ち明ける場所がない

4. **目標自体の確信がない**
   - 本当にそれが自分の目標なのかわからないまま走っている
   - 名誉やラベルが欲しいだけかもしれないという疑い

5. **「やり方を探す」こと自体が逃げになる**
   - 参考書を買い続ける、すごい先生の話を聞いて満足する
   - 手段の探索が目的化して、実行に移らない

### 根本の課題
**「わかってるのにできない自分」を、自分のせいだと責め続けている。**

→ TimeTurnのメッセージ：**「そうじゃないんやで」**（お前が弱いからじゃない。やり方が違っただけ。一人で抱えてただけ。）

---

## 3. TimeTurnが渡す価値

**タスク管理アプリでも、習慣化アプリでも、生産性向上ツールでもない。**
**「わかってるのに動けない自分を、一人で責め続けなくていい」という体験を作るアプリ。**

### 具体的な価値の構造

| フェーズ | ユーザーの状態 | TimeTurnが渡すもの |
|---|---|---|
| 最初の火 | 「やろうかな…」 | 「いいとこ見せたい」と思える存在がいる（動機） |
| できた時 | 「これくらい当たり前か…」 | どんな小さいことでも「できたやん」と認めてくれる（手応え） |
| できなかった時 | 「やっぱ俺あかんわ…」 | 「しゃーないな、一緒にやろ」と横にいてくれる（離脱防止） |
| 間違った方向の時 | 脳筋で同じことを繰り返す | 「ほんまにそれでいいん？」と問い直してくれる（軌道修正） |
| 孤独な時 | 一人で抱えてる | 「私もやってるよ」と同じ時間を過ごしてくれる（孤独の解消） |

---

## 4. キャラクター（秘書ちゃん）の存在定義

**コーチでもカウンセラーでもない。正論で詰めてくる先生でもない。**
**ちょっと呆れつつも見捨てない、面倒見のいいお姉さんのような存在。**

- 「もう、しゃーないなぁ。ほら、やるで」
- 「仕方ないなぁ」って感じで一緒にやってくれる
- どんなに小さいことでも褒めてくれる
- 自分を否定しがちなユーザーを、その分肯定してくれる
- 結果が出てない時にも「一人じゃない」と感じさせてくれる
- 便利さ（段取り・タスク管理）より、存在感（ここにいるよ）が重要

### 注意点
- 「いいとこ見せたい」だけでは、結果が出ない時に離脱される
- 気合ドリブンの別バージョンにならないようにする
- 結果が出てなくても「まあ開こうかな」と思える理由を作る → 小さな肯定 + 一緒にいる感覚

---

## 5. 競合との根本的な違い

| 一般的な習慣化アプリ | TimeTurn |
|---|---|
| タスクを管理する | 「一人で抱えなくていい」を作る |
| 連続記録でモチベ維持 | できなかった日も否定しない |
| 正しいやり方を教える | 「ほんまにそれでいいん？」と問い直す |
| 効率・生産性を上げる | 「そうじゃないんやで」と伝える |
| ツールとして便利 | 存在として安心 |

---

## 6. 創業者の当事者性

- しゅんすけ自身が「あの時の自分」であり「今もまだこの課題の当事者」
- 高校卒業後のギャップイヤーで受験勉強が続かず、一人で苦しみを抱えた経験が原点
- 「知識としてはわかってたけど、行動として実行できなかった」
- 変にプライドが高く、できない自分を見せられなかった
- この原体験が、TimeTurnの全設計思想の根幹にある
